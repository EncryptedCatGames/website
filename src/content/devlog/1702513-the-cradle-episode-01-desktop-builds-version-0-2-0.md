Thank you for supporting the game. Here's the native build for Windows and for Linux and Steam Deck: the same game as the browser version (including Halloween, the new opening and the new look), as a standalone app.

**Windows**

-   `TheCradle-Setup-0.2.0-x64.exe` installs the game, with Start-menu and desktop shortcuts.
-   `TheCradle-0.2.0-x64-portable.exe` runs without installing; put it anywhere.
-   These builds aren't code-signed yet, so Windows SmartScreen may show "Windows protected your PC". Click **More info → Run anyway**.

**Steam Deck and Linux**

-   `TheCradle-0.2.0-x86_64.AppImage` is the game.
-   `TheCradle-install.sh` is optional but recommended. Put it next to the AppImage and run it once in Desktop Mode. It adds a menu entry and the game's icon.
-   Then, in Steam, go to **Add a Non-Steam Game** and pick **The Cradle** to play it in Game Mode with the Deck's controls.

Saves are kept per device. The desktop app has its own saves, separate from the browser's.
